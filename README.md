# PasswordPorter

🚨WARNING: This is almost entirely vibe-coded slop. I haven't reviewed the code closely and it seems overengineered. 🚨

This is a .NET library (plus a terminal front-end) move saved passwords around between different web browsers and password managers. Currently it supports Firefox, KeePass KDBX files, and CSV files, but I might add more sources in the future (at least chrome).
