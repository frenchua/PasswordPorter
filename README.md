# PasswordPorter

🚨WARNING: This is mostly vibe-coded slop, **User Beware**. I haven't reviewed the code that closely... it seems overengineered... 🚨

This is a .NET library (plus a terminal front-end) that moves saved passwords around between different web browsers and password managers. Currently it supports Firefox, KeePass KDBX files, and CSV files, but I might add more sources in the future (at least Chrome and Edge).

It supports both the legacy .NET Framework 4.8 (which is preinstalled on all modern copies of Windows) and modern .NET.
